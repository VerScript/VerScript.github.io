Lightweight C Core

VerScript is built on a minimal C foundation. It includes a custom lexer and interpreter designed for fast tokenization and zero-overhead execution.

Dynamic Types & Expressions

Enjoy dynamic typing with support for strings, integers, and booleans. Effortlessly concatenate variables and evaluate mathematical expressions directly.

Indented Loops & Iteration

Supports clean indented loop structures (loop n) and variable iteration bounds (iterate i from x to y step z) compiled on the fly.

Exception Handling & Fallbacks

Supports robust try-catch mechanisms with named compiler errors via do-unless [error], as well as condition fallbacks do-unless [bool].

Polyglot Code Injection

Embed and execute code snippets from 100+ major languages (Python, JS, C++, Rust, Go, Java, SQL...) directly inside VerScript using inject [lang].

Multiline Comments

Support for block multiline comment structures (!! ... !!) to comment out large code blocks or documentation notes across lines.

Command Attributes & Kwargs

Attach optional modifiers and keyword arguments directly to commands using ?attribute (e.g. ?color="green", ?newline=false, ?default="val").

Command Aliasing & Remapping

Dynamically bind command names and map attribute signatures with the alias keyword (e.g. alias display: print or alias: blocks).
