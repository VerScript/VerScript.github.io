            Engine Highlights
            
Built for Modern Systems & Polyglots

            
Engineered from ground up with concise syntax, predictable execution semantics, and extreme flexibility.

        


        

            

                
🧩

                
Command-Query Purity

                
Strict CQS architecture: pure inbound functions with reply, stateful outbound methods, and explicit set variable scoping.

                
def func add a b { reply a + b }

            


            

                
🎨

                
Truecolor ANSI Engine

                
Output rich 24-bit Truecolor gradients (?color=#hex) and 16 named ANSI colors with non-blocking inline printing attributes.

                
display "Matrix" ?color=#00ffcc ?inline

            


            

                
🛡️

                
Reactive Watch Conditions

                
Internal watchdogs halt execution and transfer control the exact instant a variable crosses a safe threshold during block passes.

                
do ... unless internal temp > 100

            


            

                
🌐

                
100+ Language Injection

                
Embed raw source code from Python, JS, Rust, C, Go, Java, and SQL directly inside scripts, or run dynamic inject verscript eval.

                
inject python ?color="yellow"

            


            

                
🏷️

                
Custom Grammar Aliases

                
Remap built-in commands and customize keyword signatures or attribute names at runtime to craft domain-specific languages.

                
alias display: print ? color=tint

            


            

                
🔄

                
Stepped Iteration & Loops

                
Clean count loops, range iterators with custom step increments, dynamic while guards, and until condition loops.

                
iterate i from 1 to 50 step 5

            


            

                
⚡

                
Scoped Error Directives

                
Declaratively control error tolerance with SuppressErrors, CriticalErrors, and ForceErrors block scopes.

                
SuppressErrors { invalid / 0 }

            


            

                
📦

                
Heterogeneous Arrays

                
Native arr collection type supporting mixed data types, zero-indexed access, and in-place element mutation with bounds checking.

                
arr items: [1, "two", true]; items[0]: 99

            


            

                
🏛️

                
Classes, Entities & Libraries

                
Encapsulated blueprints (class) instantiating entities with static/dynamic scopes, plus pure functional static modules (lib).

                
class Hero(name) { dynamic: hp: 100 }
